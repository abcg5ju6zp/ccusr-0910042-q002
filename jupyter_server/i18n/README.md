# 国际化维护说明

本目录保存 Jupyter Server 的本地化资源。服务启动时可根据语言环境变量和请求语言偏好选择翻译目录；控制台消息与页面消息可能使用不同的加载时机，因此维护者应分别验证启动阶段和请求阶段的回退行为。

## 资源更新

使用 Babel 工具从 Python 源码和模板提取消息，翻译完成后将资源编译为运行时格式。语言代码、目录层级和消息域必须保持一致，新增语言还要同步更新支持列表。

## 维护原则

- 使用完整句子作为可翻译单元，避免通过拼接片段构造消息。
- 复数形式交由本地化接口处理，不在业务代码中追加固定后缀。
- 修改资源后同时检查默认语言、缺失翻译回退和语言环境切换。
